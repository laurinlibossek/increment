## How finishing a workout from a routine works

Reference for anyone touching the summary or routines.

- `templateChanges(template, workout)` (`core/templates.js`) returns `{ addedExercises, removedExercises, reordered, addedSets, removedSets, typesChanged, sidesChanged, supersetsChanged, valueSets, structure }`. Exercises pair by exercise id and occurrence (the 2nd Bench Press with the 2nd); sets pair warm-up to warm-up and working set to working set, each in order within left/right/untagged when both lists carry sides (otherwise in the old positional order), so a skipped warm-up doesn't shift weights.
- Sets that are unchecked or empty at finish are dropped, so they count as removed. That holds after Finish early too.
- **Progressive overload (Laurin's decisions of 4 Nov 2026, PR #10 and #15).** Increment is about lifting more over time, so finishing a workout from a routine raises the routine's numbers by itself, and they only ever go up:
  - Per set, paired as above, the routine takes the done set's numbers only when they're better (`compareSets` in `core/templates.js`): more weight, or the same weight and more reps; for assisted exercises less assistance (then more reps); for time-only exercises (planks, holds) more time; for cardio (distance and time) more distance, or the same distance in less time (Laurin, 4 Nov 2026; sets without a distance count by time, and a set without a time is never faster). Equal or worse sets keep the routine's numbers; skipped sets and exercises keep theirs. The routine's own set types and RPE targets stay.
  - If the layout changed too (a set more or fewer, an exercise added, removed, swapped or moved, set types or supersets), a small popup asks once, right after Finish, over the summary: "Change Push A?" with what differs as a diff (Laurin, 5 Nov 2026): one line per exercise, "+ Cable Fly × 3" on a green marker for what the routine would gain, "− Pull Up × 4" on a red one for what it would lose, "− Bench Press × 4 → 3" when only its number of straight sets changed (+ when it grew); × counts straight sets, normal and failure (core `templateChanges(...).sets`). Then plain lines, without a count, for the rest: "Warm-ups changed", "Drop sets changed", "Failure sets changed" (a kept exercise has a different number of them), "Supersets changed", "Order changed", "Sides changed" (after "Set types changed" when present). Increment encourages warm-ups and then straight sets, so intensifiers get a line of their own and Keep routine stays the easy choice; Update routine remembers all of them (set types, drop sets, failure sets, supersets) (Laurin, 5 Nov 2026); plus "Your better numbers are saved either way." when some were, **Keep routine** as the main button (the layout stays; the better numbers are saved) or **Update routine**. People are expected to stick to their routines and beat their numbers, so changing the layout takes a second step (Laurin, 5 Nov 2026): Update routine asks "Update Push A?" again, with the same diff and "Next time, Push A starts with this workout's exercises and sets."; its confirm button is red when anything is removed, and **Go back** returns to the first question. Confirmed, the routine takes the workout's exercises and sets; paired sets still only go up, new ones take what was done; the routine's own exercise notes stay.
  - Only numbers changed: no popup; the summary says "New numbers for 4 sets in Push A". The toast offers Undo after either case; Undo puts the routine back as it was before the workout.
  - This replaced the summary's switch row (phase 4) and the choice to keep the routine's numbers as they were. Nothing happens for example routines, "Do this workout again" or empty workouts.
  - Settings → "Update routines after workouts" (was "Ask to update templates"; same setting, `askTemplateUpdate`, on by default): off means routines only change in the editor.
